What The Scraper Does

Four required endpoints wrapped in a reviewer-friendly interface.

01

Generate Email

GET /api/email opens the browser session and extracts the active temp address.

02

Monitor Inbox

GET /api/inbox returns sender, subject, timestamp, ID, and preview.

03

Read Content

GET /api/email/{id} resolves a message and returns text, HTML, and metadata.

04

Refresh Session

POST /api/email/refresh creates a fresh mailbox and resets cached inbox state.
